# 📊 AI-Powered Sales Data Analysis Dashboard

An interactive sales analytics dashboard built using Python, Pandas, Plotly, and Streamlit. The application allows users to upload sales datasets, filter data, analyze business performance, visualize trends, and generate automated business insights.

## 🚀 Features

- 📂 CSV dataset upload
- 🔎 Region, category, and date filters
- 💰 Total sales and profit analysis
- 📦 Quantity and order tracking
- 📊 Profit margin calculation
- 🛒 Average order value
- 🌎 Regional sales analysis
- 🛍️ Category performance analysis
- 📅 Monthly sales trends
- 🏆 Top product analysis
- 💵 Sales vs. profit comparison
- 🤖 Automated business insights
- 🧹 Data quality analysis
- 📋 Interactive raw dataset viewer

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- CSV

## 🎯 Project Objective

The goal of this project is to transform raw sales data into meaningful business insights through interactive data analysis and visualization.

## 📈 Key Analysis

The dashboard helps identify:

- Highest-performing regions
- Best-selling products
- Top-performing categories
- Profitability trends
- Sales performance over time
- Data quality issues
